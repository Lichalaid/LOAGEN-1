CEJAS
Descripción:
Este flujo guía al usuario cuando menciona "cejas" o expresa la intención de agendar, modificar o cancelar una cita para este servicio.

Ejemplos de intenciones:

"Quiero hacerme las cejas"
"Necesito una cita para perfilado de cejas"
"¿Hacen microblading?"
"Quiero agendar un laminado de cejas"
"Necesito cambiar mi cita de shading"
"Quiero cancelar mi cita de microshading"
Criterio:
Si el usuario menciona "cejas" o términos relacionados como "perfilado", "microblading", "shading" o "laminado", se redirige al flujo correspondiente.

CANCELAR
Descripción:
Este flujo se activa cuando el usuario quiere cancelar una cita sin especificar el servicio o usa palabras clave como "cancelar", "anular" o "dar de baja una cita".

Ejemplos de intenciones:

"Quiero cancelar mi cita"
"Necesito anular mi reserva"
"¿Cómo cancelo mi cita en el salón?"
"Deseo dar de baja mi cita"
Criterio:
Si el usuario menciona la intención de cancelar una cita sin especificar el servicio, se le debe preguntar por el tipo de cita que desea cancelar o redirigirlo al flujo correspondiente.

FAQ
Descripción:
Este flujo responde preguntas generales sobre los servicios, precios, horarios y ubicación del salón. También se activa si el usuario solo escribe "necesito una cita".

Ejemplos de intenciones:

"Hola, ¿cómo estás?"
"¿Cuáles son los precios?"
"¿Qué servicios ofrecen?"
"¿Dónde están ubicados?"
"¿Atienden los domingos?"
"Necesito una cita"
Criterio:
Si el usuario solicita información general o solo menciona "necesito una cita" sin especificar el servicio, se le debe redirigir a este flujo.
