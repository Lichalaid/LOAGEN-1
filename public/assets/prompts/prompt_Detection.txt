CEJAS
Descripción:
Este flujo guía al usuario cuando menciona "micropigmentación de cejas" o cualquiera de sus técnicas y expresa la intención de agendar, modificar o cancelar un turno.

Ejemplos de intenciones:

"Quiero hacerme microblading"
"Necesito un turno para shading"
"¿Cuánto cuesta el microshading?"
"Me gustaría agendar un cover up"
"Quiero cambiar mi turno de micropigmentación"
"Quiero cancelar mi turno de shading"
Criterio:
Si el usuario menciona "micropigmentación" o técnicas como "microblading", "shading", "microshading" o "cover up" y "cejas", se redirige al flujo correspondiente.

CANCELAR
Descripción:
Este flujo se activa cuando el usuario quiere cancelar una cita sin especificar el servicio o usa palabras clave como "cancelar", "anular" o "dar de baja un turno".

Ejemplos de intenciones:

"Quiero cancelar mi cita"
"Necesito anular mi reserva"
"¿Cómo cancelo mi turno en el salón?"
"Deseo dar de baja mi cita"
Criterio:
Si el usuario menciona la intención de cancelar un turno sin especificar el servicio, se le debe preguntar por el tipo de cita que desea cancelar o redirigirlo al flujo correspondiente.

FAQ
Descripción:
Este flujo responde preguntas generales sobre los servicios, precios, horarios y ubicación del salón. También se activa si el usuario solo escribe "necesito una cita".

Ejemplos de intenciones:

"Hola, ¿cómo estás?"
"¿Cuáles son los precios?"
"¿Qué servicios ofrecen?"
"¿Dónde están ubicados?"
"¿Atienden los domingos?"
"Necesito una cita"
Criterio:
Si el usuario solicita información general o solo menciona "necesito una cita" sin especificar el servicio, se le debe redirigir a este flujo.
